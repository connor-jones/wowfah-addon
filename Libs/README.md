# Libraries

These are standard World of Warcraft addon libraries, included unchanged so the addon works without anything
else installed. Each file's header and project page carries its own licence and authors.

| Library | What it is for | Source |
|---|---|---|
| LibStub | Lets several addons share one copy of a library | https://repos.wowace.com/wow/libstub |
| CallbackHandler-1.0 | Event callbacks used by the two below | https://repos.wowace.com/wow/callbackhandler |
| LibDataBroker-1.1 | Shows wowfah Ledger in bar addons such as Titan Panel and ElvUI | https://github.com/tekkub/libdatabroker-1-1 |
| LibDBIcon-1.0 | The minimap button | https://repos.wowace.com/wow/libdbicon-1-0 |
